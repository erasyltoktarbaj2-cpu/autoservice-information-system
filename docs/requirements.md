# Автосервис ақпараттық жүйесіне қойылатын талаптар

## Жобаның мақсаты

Автосервис жұмысын автоматтандыру және клиенттер, автокөліктер,
жөндеу жұмыстары мен қызметтер туралы ақпаратты басқару.

## Функционалдық талаптар

- Клиенттерді тіркеу
- Автокөліктерді тіркеу
- Жөндеу тапсырысын құру
- Қызмет түрлерін басқару
- Қызметкерлер туралы ақпарат сақтау
- Тапсырыс мәртебесін өзгерту
- Жөндеу құнын есептеу
- Тапсырыстарды қарау

## Пайдаланушылар

- Әкімші
- Қызметкер
- Клиент
