# Use Case — Автосервис ақпараттық жүйесі

## Актерлер

### Әкімші
- Қызметкерлерді басқару
- Клиенттерді басқару
- Қызмет түрлерін басқару
- Жүйедегі ақпаратты бақылау

### Қызметкер
- Клиентті тіркеу
- Автокөлікті тіркеу
- Жөндеу тапсырысын қабылдау
- Тапсырыс мәртебесін өзгерту
- Жөндеу құнын енгізу

### Клиент
- Автокөлігін тіркеу
- Жөндеу тапсырысын қарау
- Тапсырыс мәртебесін тексеру

## Негізгі сценарий

1. Клиент автосервиске келеді.
2. Қызметкер клиент туралы ақпаратты енгізеді.
3. Автокөлік туралы ақпарат жүйеге енгізіледі.
4. Жөндеу тапсырысы құрылады.
5. Қажетті қызметтер таңдалады.
6. Қызметкер жөндеу жұмыстарын орындайды.
7. Тапсырыстың мәртебесі жаңартылады.
8. Жөндеу құны есептеледі.
9. Тапсырыс аяқталады.
