# Автосервис ақпараттық жүйесіне қойылатын талаптар

## 1. Жобаның мақсаты

Автосервис ақпараттық жүйесі автосервис қызметін автоматтандыруға арналған.
Жүйе клиенттерді, автокөліктерді, қызметтерді және жөндеу тапсырыстарын басқаруға мүмкіндік береді.

## 2. Функционалдық талаптар

Жүйе келесі мүмкіндіктерді қамтамасыз етуі керек:

1. Клиенттерді тіркеу.
2. Автокөліктер туралы ақпаратты сақтау.
3. Клиенттің автокөлігін жүйеге қосу.
4. Жөндеу тапсырысын құру.
5. Автосервис қызметтерін тіркеу.
6. Қызметкер туралы ақпаратты сақтау.
7. Тапсырыстың орындалу мәртебесін өзгерту.
8. Жөндеу құнын есептеу.
9. Тапсырыстар туралы ақпаратты қарау.

## 3. Негізгі пайдаланушылар

- Әкімші
- Автосервис қызметкері
- Клиент

## 4. Функционалдық емес талаптар

- Жүйе қолдануға ыңғайлы болуы керек.
- Деректер қауіпсіз сақталуы керек.
- Ақпаратты жылдам іздеу мүмкіндігі болуы керек.
- Жүйе тұрақты жұмыс істеуі керек.
