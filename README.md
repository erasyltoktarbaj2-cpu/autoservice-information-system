# Автосервис ақпараттық жүйесі

## Жоба туралы

Бұл жоба автосервис жұмысын автоматтандыруға арналған ақпараттық жүйе.

## Негізгі мүмкіндіктері

- Клиенттерді тіркеу
- Автокөліктер туралы ақпаратты сақтау
- Автокөліктерді жөндеуге қабылдау
- Қызмет түрлерін басқару
- Жөндеу жұмыстарын есепке алу
- Қызмет көрсету тарихын сақтау
